# PlayWave

Aplikasi Flutter sederhana untuk mencoba tiga jenis media:

- Memilih dan menampilkan foto dari galeri.
- Memutar audio online dengan kontrol play, pause, seek, dan kecepatan.
- Memutar video tutorial YouTube dengan kontrol pemutar.

## Menjalankan aplikasi

```bash
flutter pub get
flutter run
```

Pemutar audio dan video membutuhkan koneksi internet. Pada iOS, aplikasi
meminta izin galeri hanya saat pengguna memilih foto.
